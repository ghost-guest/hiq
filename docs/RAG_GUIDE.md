# RAG 知识库使用指南

## 概述

RAG（Retrieval-Augmented Generation）知识库是 hiq 的核心功能之一，允许您将文档导入知识库，通过语义搜索和知识图谱为 AI 提供上下文参考。

## 功能特性

- **文档导入**：支持 md/docx/pdf/xlsx/csv/代码等格式
- **全文搜索**：基于 SQLite FTS5 的高效搜索
- **知识图谱**：实体提取 + 关系发现 + 可视化图谱
- **深度提取**：使用 LLM 从文档中提取结构化知识
- **语义搜索**：基于 embedding 的相似度搜索（需配置 embedding 模型）

## 快速开始

### 1. 导入文档

在资料库面板中：
- 点击「导入文件」按钮选择文件
- 或直接拖拽文件到资料库区域

### 2. 搜索知识

- **关键词搜索**：在搜索框输入关键词
- **语义搜索**：切换到语义模式（需配置 embedding 模型）
- **@引用**：在对话中使用 `@文件名` 引用知识库内容

### 3. 深度提取

- 选择文档 → 点击「深度提取」
- 选择提取模板（通用知识图谱、金融分析、医学知识等）
- 等待提取完成，查看知识图谱

## 配置

```toml
[cowork]
# Embedding 模型（可选，启用语义搜索）
embedding_model = "qwen/qwen3-embedding"

# 提取模型（可选，用于深度提取）
extract_model = "deepseek/deepseek-v4-flash"
```

## 最佳实践

1. **按项目组织**：每个项目使用独立的知识库集合
2. **定期更新**：文档更新后重新导入以保持知识库最新
3. **使用 @引用**：在对话中直接引用知识库内容，比手动粘贴更高效
4. **深度提取**：对重要文档进行深度提取，获得结构化知识图谱
