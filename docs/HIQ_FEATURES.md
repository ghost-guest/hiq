# hiq 功能全景

> hiq 是面向通用多模型生态的企业级全场景 AI 助手，基于 Wails 桌面框架（Go 后端 + React 前端）构建。单一静态二进制，零运行时依赖，支持 Windows / macOS / Linux。

---

```
┌─────────────────────────────────────────────────────────────────┐
│                        用户入口                                  │

│  │ CLI  │  │ Desktop  │  │ HTTP │  │ IM Bot │  │ ACP  │       │
│  │ TUI  │  │ (Wails)  │  │ /SSE │  │飞书/微信│  │远程  │       │
│  └──┬───┘  └────┬─────┘  └──┬───┘  └───┬────┘  └──┬───┘       │
│     └───────────┴───────────┴──────────┴──────────┘            │
│                           │                                     │
│              ┌────────────▼────────────┐                       │
```

**五种运行模式：**

| 模式 | 命令 | 说明 |
|------|------|------|
| 终端 TUI | `hiq chat` | Charm Bubble Tea 沉浸式终端 |
| API 服务 | `hiq serve` | HTTP/SSE 编程接口 |
| 桌面客户端 | 双击图标启动 | 原生多标签页 UI |
| IM 机器人 | `hiq bot start` | 飞书/微信/QQ 网关 |
| ACP 服务 | `hiq acp` | Agent Control Protocol 远程控制 |

## 1. AI 对话

### 多模型支持

内置 300+ 模型预设，通过统一 Provider 抽象接入多家厂商：

```
┌─────────────────────────────────────────────────────┐
│  通义千问    │ qwen3.6-35b / 27b, qwen3.5-397b      │
│  DeepSeek   │ deepseek-v4-flash                      │
│  智谱 GLM   │ glm-5.1 / 5.2                          │
│  MiniMax    │ minimax-m2.7 / m2.5                     │
│  Kimi       │ kimi-k2.6 / k2.5-thinking              │
└─────────────────────────────────────────────────────┘
```

每个 provider 支持 `models` 数组多模型共享，`models_url` 自动拉取模型列表。

### 思维链展示

支持 `reasoning_content` 协议，思维过程可展开/折叠：

```
┌─────────────────────────────────────────┐
│ 🤔 思考中...                    [展开 ▼] │
│ ┌─────────────────────────────────────┐ │
│ │ 让我分析一下这个问题...              │ │
│ │ 首先需要理解题目的意思...            │ │
│ └─────────────────────────────────────┘ │
│                                         │
│ 答案是 42。                              │
└─────────────────────────────────────────┘
```

- `expand_thinking`：默认展开/折叠
- `reasoning_language`：思维语言（auto/zh/en）独立于回答语言

### 会话管理

- 多标签页，每个标签独立项目空间
- 上下文压缩：50% 提示 → 80% 触发压缩 → 90% 强制压缩
- 记忆系统：`remember` / `forget` / `recall` 工具 + 自动记忆
- Dream（7天）自动整合会话知识 → 项目记忆
- Distill（30天）自动发现重复工作流 → 打包为可复用技能

### 快捷截屏解题（考试助手）

> 使用场景：做题时截屏受限，想偷偷让 AI 解题并把结果发回来。按一下热键，AI 自动识别题目、给出答案、验证结果，通过飞书/微信推送。

**设置面板（设置 → 办公 → 快捷截屏）：**

```
┌─────────────────────────────────────────────────────────────┐
│  快捷截屏                                                    │
│                                                             │
│  图片理解模型        [qwen/qwen3.5-397b-a17b ▾]             │
│  全局图片识别的主模型。失败时自动降级到备选视觉模型。          │
│                                                             │
│  启用快捷截屏        [✓]                                    │
│  开启后，按快捷键截屏 → AI 解题 → 结果发 IM + 弹窗          │
│                                                             │
│  快捷键              [ Ctrl+Shift+Alt+W ] [录制]            │
│  组合键，修改后保存并重启生效。                              │
│                                                             │
│  解题提示词                                                │
│  ┌─────────────────────────────────────────────────────┐   │
│  │ 请从屏幕截图中找到问题，给出答案，再说明解题过程……   │   │
│  └─────────────────────────────────────────────────────┘   │
│  发送给图片理解模型的指令。可自定义解题风格。                 │
│                                    [恢复默认] [保存提示词]   │
└─────────────────────────────────────────────────────────────┘
```

**运行流程：**

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   用户按 Ctrl+Shift+Alt+W（任意应用前台）                    │
│         │                                                   │
│         ▼                                                   │
│   ┌───────────────┐   Win32 BitBlt 全屏截图                 │
│   │ CaptureScreen  │   1920×1080, ~200KB PNG                │
│   └───────┬───────┘                                         │
│           ▼                                                 │
│   ┌───────────────┐   图片 + 提示词 → VLM 模型              │
│   │  solveScreenshot│  四步结构：                            │
│   │  ① 识别题目    │  ① 识别题目 → ② 答案 → ③ 过程 → ④ 验证│
│   │  ② 给出答案    │                                       │
│   │  ③ 解题过程    │  有搜索 key → mini-agent 联网搜索      │
│   │  ④ 验证结果    │  无搜索 key → 纯 VLM 单轮             │
│   └───────┬───────┘                                         │
│           ▼                                                 │
│   ┌───────────────┐   飞书/微信 IM 推送 + 前端 toast        │
│   │  IM Push       │   🧮 截图解题结果：                     │
│   └───────────────┘                                         │
│                                                             │
│   触发方式：                                                 │
│   • 键盘热键：GetAsyncKeyState 轮询（50ms）                  │
│   • 托盘菜单：右键 → 📷 截图解题                             │
│                                                             │
│   配置项：                                                   │
│   • screenshot_enabled      开关（默认关闭）                │
│   • screenshot_hotkey       热键（默认 Ctrl+Shift+Alt+W）   │
│   • screenshot_vlm_model    模型（默认 qwen3.5-397b-a17b）  │
│   • screenshot_prompt       提示词（用户可自定义）           │
└─────────────────────────────────────────────────────────────┘
```

### 紧急停止（E-Stop）

`Ctrl+Shift+Pause`（可配置）— 桌面自动化运行时的紧急刹车，取消进行中的任务。

## 11. Office 自动化

### Word 文档

- **创建/编辑**：使用 `doc_write` 工具，支持段落、标题、列表、表格
- **图片插入**：支持 PNG/JPG/GIF/SVG 格式
- **目录生成**：自动生成可点击跳转的目录
- **格式控制**：字体、颜色、对齐、样式

### Excel 表格

- **创建/编辑**：使用 `xlsx_write` 工具，支持多 Sheet
- **图表支持**：柱状图、折线图、饼图、散点图
- **条件格式**：单元格条件、数据条、色阶
- **公式支持**：内置公式计算

### PPT 演示

- **模板系统**：`ppt_active_template` 选择模板
- **两种模式**：`fast`（单轮）/ `validate`（生成+检查+返工）
- **SVG 自由设计**：完全自由的布局设计
- **动画效果**：支持 fade、fly、zoom 等动画
- **过渡效果**：支持 fade、slide、zoom 等过渡
- **CUA 驱动**：像人一样操作 WPS Presentation（打开→感知→点击→输入）
- **嵌入二进制**，首次运行释放到 `~/.hiq/skills/ppt-auto/`

## 14. 安全与权限

### 权限系统

```
┌─────────────────────────────────────────────────────────┐
│  规则格式：subject pattern → tool pattern → allow/ask/deny│
│                                                         │
│  示例：                                                  │
│  • * → bash → ask          （所有 bash 需审批）          │
│  • * → write_file → allow  （写文件自动允许）            │
│  • * → email_send → ask    （发邮件需审批）              │
│  • * → rag_delete → ask    （删知识库需审批）            │
│                                                         │
│  glob 匹配：* 通配符，deny 规则不可绕过                  │
└─────────────────────────────────────────────────────────┘
```

### 沙箱

- Bash 沙箱模式：限制文件系统访问
- 写入根 / 读取根：限制操作范围
- 网络出口：控制网络访问
- `filepath.IsLocal` 防止路径穿越

### 检查点 / 回滚

代码修改自动快照，`/rewind` 一键回滚到任意检查点。
